# lib 폴더 — 계산을 담당하는 "머리"

## ⛔ 코덱스(디자인 담당 AI)는 이 폴더를 절대 수정하면 안 됩니다

여기에는 채점 방식, 타이머, BPM 계산 같은 **규칙**이 들어 있습니다.
화면이 어떻게 생겼든 이 계산은 그대로여야 합니다.

---

## 파일별 하는 일

| 파일 | 하는 일 |
|---|---|
| `scoring.ts` | 몇 개 맞았는지 → 몇 퍼센트인지 계산, 통과/탈락 판정 |
| `cpr.ts` | 탭 간격으로 BPM 계산, 분당 100~120회 안인지 판정 |
| `triage.ts` | 미션 1 채점 (환자를 맞는 구역에 놓았는지) |
| `ambulance.ts` | 미션 2 채점 (신고 순서 + AED 패드 + 세 점수 합치기) |
| `health-room.ts` | 미션 3 채점 (선택지 + 보건일지) |
| `badges.ts` | 배지를 받았는지 판정 |
| `nurse-type.ts` | 최종 간호 유형 판정 |
| `unlock.ts` | 통과 코드 네 자리가 맞는지 확인 |
| `session.ts` | 학생 한 명의 진행 상황 (이름, 난이도, 성적, 배지) |
| `timer.ts` | 걸린 시간, 남은 시간, 날짜 표시 |

## 화면을 만드는 사람이 알아야 할 것

**화면 코드에 숫자를 직접 쓰지 마세요.** 여기 있는 함수를 부르세요.

```
❌ 나쁜 예   if (bpm >= 100 && bpm <= 120) { ... }
✅ 좋은 예   if (isGoodRhythm(bpm)) { ... }

❌ 나쁜 예   if (accuracy >= 60) { ... }
✅ 좋은 예   if (isPassing(tally, difficulty)) { ... }

❌ 나쁜 예   if (code === "1004") { ... }
✅ 좋은 예   if (isValidUnlockCode("er", code)) { ... }
```

이렇게 해두면 선생님이 `data/rules.ts` 숫자 하나만 고쳐도
앱 전체가 알아서 따라갑니다.

## 여기 있는 계산이 맞는지 확인하는 법

```
npm run test:data
```

`scripts/check-data.ts` 가 다음을 자동으로 확인합니다.

- 100과 120이 "알맞음"으로 판정되는지
- 정확한 리듬으로 오래 누르면 만점이 나오는지
- 몇 번만 누르고 멈추면 통과가 안 되는지
- 초등 60% / 중등 75% 기준이 정확히 적용되는지
- 통과 코드가 미션마다 다르고 아무 코드나 통과되지 않는지
- 모든 문제에 정답이 정확히 하나씩 있는지
