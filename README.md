# 골든타임 — 간호사 진로체험 웹앱

초등 3학년~중학생 대상 **학교방문 진로체험 수업**용 웹앱입니다.
학생이 태블릿으로 간호 현장 여섯 곳(응급실 / 119 구급차 / 병동 / 수술실 / 중환자실 / 투약실)을 체험하고,
마지막에 자기에게 맞는 간호 분야를 확인합니다.

> 이 문서는 **선생님(비개발자)용** 사용 설명서입니다.
> 디자인을 다시 만드는 AI 를 위한 문서는 [`REDESIGN_GUIDE.md`](./REDESIGN_GUIDE.md) 입니다.

---

## 학생이 겪는 흐름

```
시작 화면 ──▶ 로비(병원 조감도) ──▶ 미션 ──▶ 통과 코드 ──▶ 로비
   이름·난이도            부서 여섯 곳              강사가 부르는 4자리
                              │
                              └── 배지 6개를 다 모으면 ──▶ 최종 리포트 + 수료증
```

**통과 코드**는 반 전체 진도를 맞추는 장치입니다.
미션을 먼저 끝낸 학생은 코드 입력 화면에서 기다리고,
선생님이 오답 토론을 마친 뒤 칠판에 네 자리를 적어주면 그때 다음으로 넘어갑니다.

| 미션 | 통과 코드 |
|---|---|
| 미션 1 응급실 | `1004` |
| 미션 2 119 구급차 | `2119` |
| 미션 3 보건실 | `3365` |
| 미션 4 수술실 | `4404` |
| 미션 5 중환자실 | `5505` |
| 미션 6 투약실 | `6606` |

## 학교에 안심하고 가져가도 되는 이유

- **로그인이 없습니다.**
- **학생 정보를 서버로 보내지 않습니다.** 이름은 수료증에 표시하는 용도로만 쓰이고
  브라우저 안에만 있다가 **새로고침하면 즉시 사라집니다.**
- 그래서 개인정보 수집·저장이 전혀 없습니다.
- 인터넷이 끊겨도 화면이 열립니다.
- 소리는 **기본 꺼짐**입니다. 켜고 싶은 학생만 켭니다.

---

## 수업 중 학생에게 안내할 것

- 미션 1에서 환자 카드는 **끌어다 놓아도 되고, 구역을 그냥 눌러도 됩니다.**
  (드래그를 어려워하는 학생을 위해 두 방법 모두 됩니다)
- 미션 2 가슴압박은 **원이 가장 작아질 때** 누릅니다.
- 오답 해설을 읽는 동안에는 **제한시간이 멈춥니다.** 천천히 읽어도 손해가 없습니다.

## 수업 내용을 바꾸고 싶을 때

수업 내용은 전부 **`data/` 폴더 한 곳**에 있습니다. 화면 코드는 손댈 필요가 없습니다.

| 바꾸고 싶은 것 | 고칠 파일 |
|---|---|
| **가장 중요.** 통과 기준·제한시간·통과 코드·CPR 속도 | `data/rules.ts` |
| 응급실 환자 카드와 정답, 해설 | `data/triage-patients.ts` |
| 응급실 색깔 구역 | `data/triage-zones.ts` |
| 119 행동 순서 | `data/dispatch-steps.ts` |
| AED 패드 붙일 자리 | `data/aed-pads.ts` |
| 보건실 상황과 선택지 | `data/health-room-cases.ts` |
| 보건일지 문장 (중등) | `data/health-log.ts` |
| 수술실·중환자실·투약실 활동 | `data/specialty-missions.ts` |
| 간호 유형과 진로 정보 | `data/nurse-types.ts` |
| 의료 면책·개인정보 문구 | `data/disclaimer.ts` |

### 자주 하는 수정

**통과 기준을 낮추고 싶다 (초등이 너무 어려워한다)**
→ `data/rules.ts` 에서 `PASS_THRESHOLD_PERCENT` 의 `elementary: 60` 숫자를 바꾸세요.

**가슴압박 60초가 너무 길다**
→ `data/rules.ts` 의 `CPR_DURATION_SECONDS` 에서 `elementary: 60` 을 바꾸세요.

**중등 3분 제한이 짧다**
→ `data/rules.ts` 의 `TRIAGE_TIME_LIMIT_SECONDS` 에서 `middle: 180` 을 바꾸세요.

**통과 코드를 바꾸고 싶다**
→ `data/rules.ts` 의 `UNLOCK_CODES` 에서 네 자리를 바꾸세요.

**환자 한 명의 정답 구역을 바꾸고 싶다**
→ `data/triage-patients.ts` 에서 그 환자의 `correctZone` 을
`red`(지금 당장) / `orange`(몇 분 안에·중등만) / `yellow`(빨리) /
`green`(기다려도 됨) / `blue`(가벼움) 중 하나로 바꾸세요.

### ⚠️ 고친 뒤에는 반드시

```bash
npm run test:data
```

정답을 실수로 두 개 만들었거나, 해설을 빼먹었거나,
그 난이도에 없는 구역을 정답으로 지정하는 등의 실수를
**한국어로 어디가 잘못됐는지 알려줍니다.**

## 난이도별 차이 (기획서 확정 사항)

| 항목 | 초등 모드 | 중등 모드 |
|---|---|---|
| 미션1 구역 수 | 4개 | 5개 (주황 "몇 분 안에" 추가) |
| 미션1 환자 수 | 6명 | 10명 |
| 미션1 활력징후 표시 | 안 보임 | 보임 |
| 미션1 제한시간 | 없음 | 3분 |
| 미션2 가슴압박 시간 | 60초 | 120초 |
| 미션2 리듬 가이드 원 | 끝까지 보임 | 20초 뒤 사라짐 |
| 미션3 보건일지 | 없음 | 있음 |
| 통과 기준 | 60% | 75% |

가슴압박 속도는 두 모드 모두 **분당 100~120회**입니다.
**배지 6개를 다 모아야 최종 리포트가 열립니다.**

## 실행하기

```bash
npm install     # 처음 한 번만
npm run dev     # 내 컴퓨터에서 열기 (http://localhost:3000)
```

### 배포 (Vercel)

이 저장소를 Vercel 에 연결하면 별도 설정 없이 배포됩니다.
서버에 저장하는 데이터가 없어서 데이터베이스 설정도 필요 없습니다.

## 폴더 구조

```
data/        수업 내용 — 환자 카드, 정답, 해설, 통과 코드, 기준값
lib/         계산 — 채점, 타이머, BPM, 배지·유형 판정
components/  화면에 보이는 것 (디자인 담당 AI 가 다시 만들 부분)
app/         주소 연결
styles/      색·크기·간격을 모아둔 파일
scripts/     데이터 점검 스크립트
```

`data/` 와 `lib/` 폴더에는 각각 안내문(`README.md`)이 들어 있습니다.
