# data 폴더 — 수업 "내용"이 들어있는 곳

## ⛔ 코덱스(디자인 담당 AI)는 이 폴더를 절대 수정하면 안 됩니다

이 폴더에는 **정답과 기준값**이 들어 있습니다.
디자인을 바꾸려고 이 폴더를 건드리면 수업 내용이 망가집니다.

---

## 선생님이 수업 내용을 바꾸고 싶을 때 볼 파일

| 파일 | 무엇이 들어있나 |
|---|---|
| `rules.ts` | **가장 중요.** 가슴압박 속도·시간, 통과 기준 퍼센트, 제한시간, 통과 코드 |
| `triage-patients.ts` | 미션 1 환자 카드(초등 6명 / 중등 10명)와 정답 구역, 오답 해설 |
| `triage-zones.ts` | 미션 1 색깔 구역 (초등 4개 / 중등 5개) |
| `dispatch-steps.ts` | 미션 2 ① 쓰러진 사람 발견 시 행동 순서 5단계 |
| `aed-pads.ts` | 미션 2 ③ 자동심장충격기 패드 붙일 자리 |
| `health-room-cases.ts` | 미션 3 상황 5개 (처치 4지선다 + 다음 조치 4지선다) |
| `health-log.ts` | 미션 3 보건일지 문장 조립 (중등 모드 전용) |
| `nurse-types.ts` | 최종 리포트의 간호 유형 3가지와 진로 정보 |
| `missions.ts` | 로비 부서 3곳의 이름과 설명 |
| `disclaimer.ts` | 의료 면책 문구, 개인정보 안내 문구 |
| `types.ts` | 용어 정의 (건드릴 일 거의 없음) |

## 기획서에서 정해진 숫자 (함부로 바꾸면 수업이 어긋납니다)

| 항목 | 초등 모드 | 중등 모드 |
|---|---|---|
| 미션1 구역 수 | 4개 (빨강·노랑·초록·파랑) | 5개 (검정 추가) |
| 미션1 환자 수 | 6명 | 10명 |
| 미션1 활력징후 표시 | 안 보임 | 보임 |
| 미션1 제한시간 | 없음 | 3분 |
| 미션2 가슴압박 시간 | 60초 | 120초 |
| 미션2 리듬 가이드 원 | 끝까지 보임 | 20초 뒤 사라짐 |
| 미션3 보건일지 | 없음 | 있음 |
| 통과 기준 | 60% | 75% |

- 가슴압박 속도는 두 모드 모두 **분당 100~120회**입니다.
- **배지 3개를 다 모아야 최종 리포트가 열립니다.**

## 내용을 고친 다음에 꼭 하세요

터미널에 이렇게 치면 실수한 게 없는지 확인해줍니다.

```
npm run test:data
```

예를 들어 정답을 실수로 두 개 만들거나, 해설을 빼먹으면
**어느 문제가 잘못됐는지 한국어로 알려줍니다.**

---

## 자주 하는 수정 예시

**환자 한 명의 정답 구역을 바꾸고 싶다**
→ `triage-patients.ts` 에서 그 환자의 `correctZone` 을
`"red"` / `"yellow"` / `"green"` 중 하나로 바꾸세요.

**통과 기준을 낮추고 싶다 (초등이 너무 어려워한다)**
→ `rules.ts` 의 `PASS_THRESHOLD_PERCENT` 에서 `elementary: 60` 의 숫자를 바꾸세요.

**통과 코드를 바꾸고 싶다**
→ `rules.ts` 의 `UNLOCK_CODES` 에서 네 자리를 바꾸세요.

**환자를 한 명 더 추가하고 싶다**
→ `triage-patients.ts` 의 목록에 기존 항목 하나를 복사해 붙이고,
`id` 를 겹치지 않게 바꾼 뒤 내용을 고치세요.
